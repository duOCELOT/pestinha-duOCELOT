# Imagens deste material

Estas imagens são renderizações de Views Android reais pelo teste
[`DesignTest`](https://github.com/duOCELOT/pestinha-duOCELOT/blob/android/android/app/src/test/java/org/pestinha/android/DesignTest.java),
executado com Robolectric e gráficos nativos. Não são screenshots do aparelho
do usuário, mockups gerados por IA nem imagens de uma sessão pessoal.

| Arquivo | Conteúdo | Origem |
| --- | --- | --- |
| `inicio.png` | Tela principal com Bryan e autorização de overlay ainda pendente | Layout introduzido na 0.5 e mantido na 0.6; [compilação de referência](https://github.com/duOCELOT/pestinha-duOCELOT/actions/runs/41484854158) |
| `menu-rapido.png` | Menu de oito atalhos, no estado inicial | Mesma compilação de referência da interface 0.5 |
| `mimir.png` | Mimir com paleta azul-gelo e elmo viking | [Compilação de referência 0.6](https://github.com/duOCELOT/pestinha-duOCELOT/actions/runs/41489312528) |

O aspecto pode variar com densidade, tamanho da tela, estado do pet, permissões
e versão do Android. As imagens ilustram componentes, não todas as telas e
estados possíveis. Interface e código seguem a licença do projeto; consulte
[LICENSE](../../../LICENSE).
